## 📊 How It Works

```
Sensor Trigger (GPIO)
    ↓
Count Impulse
    ↓
Buffer in Memory (pending_count)
    ↓
Every 5 Seconds: Flush to Server
    ↓
Update Database (SensorCount.total_count)
    ↓
Check Threshold (>= 300,000?)
    ├─ NO: Continue
    └─ YES: Trigger Alert
        ├─ Notify Dashboard
        ├─ Send Email
        ├─ Show LCD Message
        └─ Log Event
    ↓
Technician Performs Maintenance
    ↓
Reset Counter (total_count = 0)
    ↓
Cycle Repeats
```

## 🎯 Conditional Maintenance Rules

```python
# Automatic status determination
if total_count >= 300000:
    status = "MAINTENANCE_DUE"
    # Alert triggered
    # Notifications sent
    # LCD shows message

elif total_count >= 240000:  # 80%
    status = "WARNING"
    # Yellow alert on dashboard
    
else:
    status = "OK"
    # Green status on dashboard

# Additional rules
if trend_increase > 50%:
    recommendation = "Heavy usage - monitor closely"

    recommendation = "Consider more frequent maintenance"
```
